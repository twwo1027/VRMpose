# VRMpose

VRM 0.x / 1.0 のモデルにポーズと表情を設定し、背景が透明な4K PNGに書き出すWindows用アプリです。

**[Windows x64版をダウンロード（VRMpose 0.1.0、約96MB）](https://github.com/twwo1027/VRMpose/raw/refs/tags/v0.1.0/downloads/VRMpose-0.1.0-x64.exe)**

## Windowsで使う

上のリンクからダウンロードした `VRMpose-0.1.0-x64.exe` を起動してください。Node.jsや別の実行環境のインストールは不要です。配布用ファイルはexeひとつですが、起動時に同梱の実行環境を一時フォルダへ展開し、ポーズ履歴をユーザーのアプリ保存領域に書き込みます。Windows 10以降の64bit環境を対象とします。ご自身の `.vrm` モデルファイルを用意してください。

現時点ではLinux上のブラウザ・Electronによる動作検証とexe生成を確認済みです。Windows実機での起動は未確認で、コード署名は設定していません。

1. **VRMを開く**からモデルを読み込みます。テクスチャ・バッファを内蔵した単一のVRMファイルに対応します。
2. プリセットや**無料の指示**を適用し、右側でボーンのXYZ回転を調整します。指、髪、服などモデル固有の追加ボーンも選択できます。腰の移動でモデル全体の位置を調整できます。
3. **表情**タブで、そのモデルが持つ表情パラメータを0〜1で調整します。
4. ドラッグでカメラ回転、右ドラッグで移動、ホイールでズームします。横長・縦長・正方形の出力比率を選んで構図を決めます。
5. **PNGを書き出す**で保存します。横長は3840×2160、縦長は2160×3840、正方形は4096×4096です。床、ボーンのガイド、背景のチェック模様は画像に入りません。
6. **マイポーズ**の＋から名前を付けて保存し、後から呼び出せます。ポーズJSONの書き出し・読み込み・削除にも対応します。

ポーズ履歴は `%APPDATA%\VRMpose\poses.json` に保存されます。exeを閉じても保持されます。VRM本体は履歴に含まれないため、次の起動時にモデルを読み込み直してください。大切なポーズはJSONでも保存してください。

## 追加API料金なしの日本語指示

**無料の指示**はアプリ内の定型処理です。生成AIや外部APIは使いません。次のような指示に対応します。

- 「右手を振って笑顔」「左手を振る」
- 「両手を上げる」「右手でピース」「左手を腰に」
- 「座る」「お辞儀」「腕を組む」「Tポーズ」
- 「右を向く」「左を向く」「笑顔」「悲しい顔」「怒った顔」「びっくり」

一部は組み合わせられます。自由な文章を完全に理解する方式ではなく、角度を使った近似ポーズなので、最後に手動で調整してください。モデルに含まれない表情は適用されません。

複雑なポーズは **ChatGPT貼り付け** を使います。

1. 作りたいポーズを日本語で入力し、**ChatGPT用の指示をコピー**します。
2. 普段使っているChatGPTを別途開き、コピーした指示を貼り付けます。
3. 返されたJSON全体をアプリの回答欄に貼り付け、**回答のポーズを適用**します。

アプリにAPIキーは不要で、アプリからAPI利用料は発生しません。ChatGPT自体のプラン・利用上限は利用中の契約に従います。この方式はコピーと貼り付けが必要です。VRMモデル自体をChatGPTにアップロードする必要はありません。

## 対応範囲

- VRM 0.x / 1.0。人体ボーンはVRMの正規化された座標系で編集・保存します。VRM0との向きの違いを変換します。
- 標準人体ボーン、存在する指の関節、スキンボーン、スプリング・制約に関連する追加ボーンを操作します。モデルに存在しないボーンは表示しません。
- 追加ボーンの識別はモデルのノード階層を使うため、同じモデルでの再利用を推奨します。別モデルでは人体ボーン・共通表情だけが一致する場合があります。
- 静止ポーズ編集のため、自動視線と髪・服の揺れは停止します。IK、足の接地補正、衝突回避はありません。
- GPUのWebGL 2対応が必要です。4K出力には相応のGPUメモリが必要です。
- モデルの利用規約・権利は、そのモデルの条件に従ってください。配布exeにキャラクターモデルは同梱していません。

## 開発

Node.js 24を推奨します。リポジトリを既存のチェックアウトで作業します。クラウドタスクごとに環境が隔離されるため、追加のGit worktreeは不要です。

```sh
npm ci
node node_modules/electron/install.js
npm test
npm run build
npm start
```

Electron 44のnpmパッケージはインストール時に実行環境を自動取得しないため、初回は `install.js` を明示的に実行します。ダウンロードのTLSとElectron公式チェックサムは維持しています。

画面だけの開発は `npm run dev` で行えます。ブラウザ版はポーズをブラウザのローカル保存領域に保存し、画像をダウンロードします。Electronで開発画面を使う場合は、開発サーバーを起動したうえで `VRMPOSE_DEV_URL=http://127.0.0.1:5173/` を設定して `npm start` を実行してください。

Windows用exeの作成:

```sh
npm run package:win
```

Electron、Chromium、必要なアプリコードがportable exeに含まれます。コード署名は設定していません。

## 検証

```sh
npm test
npm run test:smoke
npm run build
npm run test:desktop
```

`npm test` はポーズ検証、日本語指示、ChatGPT JSON、ネイティブ保存・履歴破損保護・IPCアクセス制限を確認します。`test:smoke` は合成したVRM0/VRM1モデルを実際に読み込み、腕・表情・追加ボーン・復元・4K PNGの寸法と透明な画素を確認します。`test:desktop` は実際のElectronを起動し、VRM読み込み、履歴の再起動後の保持、ネイティブPNG保存を確認します。

ブラウザ検証にはChromiumが必要です。クラウドでは `/usr/bin/chromium` を使います。別の環境では `CHROMIUM_PATH` に実行ファイルを指定してください。Linuxコンテナのテスト起動に限りChromiumの `--no-sandbox` とソフトウェアGPUを使っています。配布アプリのrenderer設定は `sandbox: true`、`contextIsolation: true` です。

Electron/Vite/Three.js/@pixiv/three-vrmを使用しています。生成したテストモデルには外部キャラクター素材を使っていません。Windowsでの実機確認はLinuxのビルド・テストとは別に行ってください。
